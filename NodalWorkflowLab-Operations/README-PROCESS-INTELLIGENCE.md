# Process Intelligence extension

See `../START-HERE.md` and `../RELEASE-NOTES.md` in the archive root for running instructions and limitations.

The new Atlas builds on the existing Fleet dashboard. It adds a synthetic operational snapshot archive, saved investigation service, rule-based dependency explanations, sample trends, site/workspace/engine scope filters, and an illustrative scenario sandbox. It does not assert that projected progress or an approval has been recorded without an authoritative module event.

**Do not place regulated or controlled information in `App_Data` or distribute saved investigations from this demo as though they were access-controlled.**
